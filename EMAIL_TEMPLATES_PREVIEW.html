🔧 Variables de Template

Les templates utilisent les variables suivantes (format Mustache {{variable}}) :

  • {{fullname}} - Nom complet de l'utilisateur
  • {{url}} - URL d'action (définir mot de passe, réinitialiser)
  • {{year}} - Année en cours pour le copyright

Note : Les variables sont remplacées automatiquement par le système d'envoi d'emails.
